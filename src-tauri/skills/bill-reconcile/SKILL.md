# 账单核对
1. 询问月份和待核对账单范围。需要文件时引导使用聊天窗口的导入账单按钮；不能声称已读取未提供的文件。
2. 调用 list_transactions 与账目搜索/异常检测工具获取当前账本事实。记录 total_count，返回条目少于总数时说明只检查了样本，不能声称全量对账通过。
3. 按日期、金额、收支类型和备注提出疑似重复项，区分退款、转账与实际消费。相同金额不代表重复。
4. 输出「核对范围、匹配情况、疑似问题、待用户确认」。不自动删除、修改或批量入账；导入使用现有导入预览与勾选确认流程。
