## Purpose

为用户提供统一的助手能力目录，清晰展示已集成的金融数据连接与专业分析流程，允许每位用户独立控制启用状态、测试可用性，并从目录开始使用能力。

## ADDED Requirements

### Requirement: 能力目录与按用户管理
系统 SHALL 展示 AKTools、yfinance MCP 和月度复盘、资产健康、ETF 对比、账单核对四个 Skill 的说明、来源、类型和启用状态，并支持搜索筛选及详情。

#### Scenario: 查看并筛选
- **WHEN** 用户打开能力市场并选择 Skill
- **THEN** 只展示四个分析流程，可查看步骤和来源并立即使用

#### Scenario: 用户隔离
- **WHEN** A 启用一个 MCP 后切换到 B
- **THEN** B 的启用状态与测试记录不继承 A

### Requirement: 真实连接测试
系统 SHALL 进行真实 MCP 握手与工具发现，显示最近测试时间、工具数量或明确的错误，不能仅凭目录存在显示已连接。

#### Scenario: 无可用运行时
- **WHEN** 用户测试 MCP 且本机缺少运行时
- **THEN** 界面显示安装指引和失败状态，仍可使用其他能力

#### Scenario: 禁用能力
- **WHEN** 用户禁用能力并发送下一条消息
- **THEN** 助手不再发现或执行该能力
