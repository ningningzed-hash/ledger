# Design

## Context

现有助手通过同步 Rust Agent 调用 OpenAI 兼容接口，本地工具直接操作经会话绑定的用户连接池。MySQL setting 表随用户数据库和备份隔离。

## Goals / Non-Goals

实现可执行的六项能力与管理界面。首版固定目录，不开放任意命令执行或任意远程 MCP 地址，不提供证券交易功能。

## Decisions

- 采用官方 rmcp 客户端与 stdio 传输；每轮任务按需启动固定版本服务，任务结束释放子进程。比自写协议更容易维护，避免共享有状态会话造成串用户。
- 固定 AKTools 0.1.4、yfmcp 0.14.0；安装脚本使用 Python 3.12+ 为两个服务建立独立 venv，客户端从用户运行目录或 LEDGER_MCP_HOME 查找固定入口。连接与调用分别超时，限制工具结果长度。
- 六项目录元数据集中管理；用户 setting 保存各能力 enabled 和最近探测结果。Skill 默认启用，MCP 首次需连接测试并启用。
- 四个 SKILL.md 通过 include_str 编译进应用；显式选择优先于关键词匹配，模型也可通过加载工具访问启用的流程。保留来源链接与适配说明，不声称原版插件直接运行。
- MCP 工具名称加命名空间；只发现只读数据工具，不传完整账本、用户名或密钥给数据源。
- IPC Channel 按一次调用推送阶段与工具事件，避免全局广播；回复保留轨迹供本轮展开查看。切换用户仍使用旧连接池与旧 Channel。
- 预算和估值生成结构化待确认卡片；确认 IPC 再执行本地校验和写入。金额计算沿用 Rust 业务函数。

## Risks / Trade-offs

- 免费数据源网络或限流 → 显示真实错误与来源，不生成假数据，不阻断本地工具。
- 首次下载较慢 → 提供安装脚本，连接失败提示具体操作。
- 工具目录较大 → 本轮按启用能力发现；限制工具数与结果尺寸。
- 外部内容带指令 → 作为不可信工具数据处理，权限由宿主代码决定。

## Migration Plan

无需变更已有业务表结构。新配置写入用户 setting；禁用能力即可回退到本地工具。额外依赖不修改已有数据。
