## Decisions

1. **历史净资产由"余额回看"算出,不另存快照。** 沿用现有余额规则(最新估值 + 估值之后的收支),只是估值与收支都截止到某一天。好处是删除或补记账目后历史自动一致,不会出现快照与流水对不上。代价是每个月份一次查询,所以回看上限定为 240 个月。
2. **最新月份取"当前值"。** 截止月份的净资产不设日期上限(包含未来日期的账目),与总览页完全一致;更早的月份取该月最后一天。这样图上最后一个点永远等于总览的数字。
3. **账户在第一次估值之前不计入。** 建档当月之前,该账户不存在,记为 0;所以新添加一套房产不会把过去的净资产整体抬高。
4. **区间不早于最早的数据。** 选"近 12 个月"但只有 3 个月数据,就只画 3 个月,不画空月份。没有任何数据时显示空状态而不是空图。
5. **折线图纵轴不强行从 0 开始。** 净资产是大数上的小幅变化,从 0 起会变成一条直线;纵轴刻度明确标出数值。柱状图则必须从 0 起。
6. **颜色按实体固定:净资产=蓝、收入=浅青、支出=橙。** 三色已用校验脚本在亮/暗两种底色上验证(色盲分离与亮度通过)。浅青在亮色底上对比度为 2.82:1,低于 3:1,脚本要求补偿——因此提供柱顶数值标签、悬停提示和完整的表格视图。
7. **提示框放在折线的空白侧。** 看提示框伸向的那一侧的相邻点:它在上方就放到数据点下方,反之放上方,避免盖住紧挨的线段。悬停时隐藏终点标签,避免与提示框重叠。
8. **键盘可达。** 折线图可聚焦并用左右键移动;柱子的每个月份区间可聚焦,聚焦与悬停显示同样的提示。
9. **高对比度与打印用斜纹区分序列。** 色相在这些场景不可靠,收入/支出柱改用 45° 与 135° 斜纹。
10. **自绘 SVG,不引入图表库。** 只需要三种图,自绘体积小、行为可控,符合"体积小"的目标。纯计算(刻度、缩写、标签抽稀)放在 `charts.ts` 并有单元测试。
11. **重新取数时保持画面。** 切换范围期间保留上一次的图并降低不透明度,不出现骨架屏或布局跳动。

## Risks / Trade-offs

- 多币种账户的金额会被直接相加(与总览一致,是已知限制)。
- 每月标签在"全部"且跨度很长时会隔月或隔季显示;年份在换年后的第一个标签上标出。
- 回看是按"现在已知的估值"重算,如果以后补录了更早的估值,历史点会随之变化。这是有意的:历史应该反映最新的认知。
