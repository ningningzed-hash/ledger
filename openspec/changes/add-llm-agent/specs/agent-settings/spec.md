## ADDED Requirements

### Requirement: 可配置的模型连接
系统 SHALL 允许用户设置模型服务地址与模型名称,默认值分别为 `http://localhost:11434` 与 `qwen3:14b`,修改后 MUST 在下一条消息生效且重启后保持。

#### Scenario: 修改模型名
- **WHEN** 用户在设置中将模型名改为另一个已安装的模型并保存
- **THEN** 之后的对话使用新模型,重启应用后设置仍然存在

### Requirement: 可编辑的人设与理财理念
系统 SHALL 提供内置的默认人设与理财理念,并允许用户编辑、保存以及恢复默认。

#### Scenario: 首次使用
- **WHEN** 用户从未修改过设置
- **THEN** 设置界面显示内置的默认人设与理财理念,助手按其行事

#### Scenario: 恢复默认
- **WHEN** 用户点击恢复默认
- **THEN** 人设与理财理念回到内置默认值,自定义内容被清除

### Requirement: 设置校验
系统 SHALL 拒绝空的模型地址或模型名。

#### Scenario: 保存空模型名
- **WHEN** 用户清空模型名并保存
- **THEN** 系统提示错误且不改变已保存的设置
