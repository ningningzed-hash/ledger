## Why

助手面板目前只是一个关键词匹配的占位实现,无法理解自然语言,也不能帮用户记账或做资产分析。用户本机已通过 Ollama 部署了 `qwen3:14b`(支持工具调用),可以在完全本地的前提下接入,财务数据不出本机。同时需要让助手具备稳定的人设和理财理念,使其给出的建议风格一致、立场保守。

## What Changes

- 助手改为由本地 Ollama 模型驱动,通过工具调用读取和写入账本数据(查询总览、账目、资产、预算;记一笔账、设置月预算、更新资产估值)。
- 新增系统提示词,包含"人设"与"理财理念"两部分,并在每轮对话中注入当前日期与账本快照。
- 新增助手设置:模型服务地址、模型名、人设、理财理念,可在客户端内修改并持久化,支持恢复默认。
- 模型服务不可用时给出明确、可操作的错误提示,而不是让界面卡死。
- 助手不提供删除类工具,避免模型误操作造成数据丢失。

## Capabilities

### New Capabilities
- `chat-agent`: 对话式财务助手的行为,包括工具调用、记账确认、数据真实性、错误处理。
- `agent-settings`: 助手的模型连接与人设/理财理念配置。
