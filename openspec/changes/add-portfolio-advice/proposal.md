## Why

账本现在只知道"投资账户值多少钱",不知道里面装的是什么。用户目前的组合只有美股市场的宽基指数,集中度很高,但应用既看不出来,也没有任何依据告诉用户"大致该往哪个方向调"。助手的理财理念里只有"分散配置""应急金优先"这类原则,没有结合用户自己的持仓、风险承受能力、现金流和目标给出可核对的数字。

## What Changes

- 新增**持仓**:给投资类账户登记持仓明细(名称、可选代码、资产大类、金额),算出各大类占比、集中度(单一大类占比过高、股票全部集中在美股宽基),并核对持仓合计与投资账户余额的差额。
- 新增**风险偏好问卷**:风险等级(保守/稳健/进取)、能接受的最大回撤、投资期限、未登记利率的负债里是否有高息的,存入设置,用于决定目标配比。
- 新增**候选产品清单**:应用内一份可编辑的产品清单(名称、代码、资产大类、说明)。首版内置少量常见示例(美股宽基、非美股票、债券、黄金、现金类),不内置费率等易过期数据,每条都标注"仅供参考,以发行方披露为准"。清单只是参考:推荐不要求可执行,不考虑购买渠道、地区与合规。
- 新增侧栏模块**"理财"**,分"组合建议"和"利息计算"两个标签页(不再挂在报表页下面,避免报表太长)。**组合建议**页:
  - 由 Rust 按规则算出目标配比(风险等级为底,再按期限、最大回撤、短期目标资金做约束),给出当前占比与目标占比的差额和再平衡金额。
  - 检查前置条件:应急金能撑几个月、是否有高息负债、近几个月平均结余,不满足时把"先补应急金/先还债"放在最前面。
  - 对低配的大类,从候选清单里列出可选产品。
  - 图表:当前 vs 目标的对比条,再平衡表,候选产品列表,都支持暗色模式与表格视图,并带"不构成投资建议"的声明。
- 新增**利息计算**(纯计算,由 Rust 完成,不内置任何银行利率):
  - 存款:活期(单利、按实际天数)、整存整取定期与大额存单(到期付息,大额存单可选按月/按年付息)、零存整取。
  - 货币基金/理财:按七日年化或预期年化做复利估算,明确标注"估算,非承诺"。
  - 贷款:等额本息、等额本金的月供与总利息;分期手续费折算的实际年化(IRR);提前还款节省的利息(缩短期限/减少月供)。
  - 每个结果都带上所用的公式与口径假设。
- 存款类、负债类账户可登记**年利率**(新表 `account_rate`),用于:每月预计利息收入/支出概览;按利率(≥8%)自动判断高息负债;组合建议里的"闲置现金放更高利率能多赚多少"与"还债每年省多少利息"。"理财"页的"利息计算"标签页提供计算器和账户利息概览。
- 助手新增三个**只读**工具(读取持仓与占比、读取建议、计算利息),模型只负责解读程序算好的结果;产品只能从候选清单里挑,不得自己编造代码或费率。
- 备份文件包含新表;旧版备份仍可恢复(新表按空表处理)。
- 调整助手的理财理念默认文本与行为规则:原先"不推荐具体的股票、基金或其他证券"改为"只在程序给出的候选清单范围内说明,不预测行情、不给买卖时点"。

## Capabilities

### New Capabilities
- `portfolio-holdings`: 持仓登记、大类占比、集中度与对账。
- `risk-profile`: 风险偏好问卷的字段、取值范围与存取。
- `product-catalog`: 候选产品清单的内容、编辑规则与首版内置示例。
- `portfolio-advice`: 目标配比规则、前置条件检查、利息视角、再平衡与候选产品、"理财"页展示、助手工具与免责声明。
- `interest-calculation`: 存款/理财/贷款的利息计算口径、账户年利率登记、利息概览与助手工具。

## Impact

- 数据库:新增 `holding`、`product`、`account_rate` 三张表,走现有 `migrate`(只用 `CREATE TABLE IF NOT EXISTS`,不改 `account` 表结构,所以余额查询、`Account` 结构体和备份的 `account` 列都不变);内置示例只在第一次启动时写入一次(用 `setting` 里的标记),用户删掉后不会复活。风险问卷存 `setting`,不新建表。
- Rust:新增 `interest.rs`(纯函数的利息计算)、`portfolio.rs`(持仓、配比、建议计算、账户利率)和相应命令;`backup.rs` 的 `TABLES` 与 `OPTIONAL` 加入新表(备份版本号不变);`agent.rs` 注册三个只读工具;`prompts/philosophy.md`、`prompts/rules.md` 修改。
- 前端:新增 `portfolio.tsx`(建议区块、持仓与问卷与清单的编辑)、`interest.tsx`(利息计算面板与账户年利率编辑),由新的 `invest.tsx`(侧栏"理财"页,含两个标签页)承载,报表页保持不变;`charts.ts` 增加对比条所需的纯函数与测试。
- 与既有设计的取舍:`add-llm-agent` 曾把"具体证券的买卖建议"列为不做。本变更只放开"在候选清单内说明有哪些可选品类/产品",仍然不预测行情、不给买卖时点,金额与比例均由程序计算。
- 已保存过自定义理财理念的用户不会自动得到新文本;`rules.md` 是编译进程序的常量,会明确说明例外规则,并建议此类用户在设置里"恢复默认"。
- 隐私:持仓与问卷只在发起助手对话时随工具结果发给用户配置的模型地址,与账目明细一致。
